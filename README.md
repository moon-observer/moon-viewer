## 项目简介

“观月”是一款以观测地点和时间为核心输入的交互式月球可视化应用。页面并非播放预先制作的月相图片，而是在浏览器中计算太阳、月球、地球和地面观测者之间的几何关系，再通过 WebGL 连续生成当前月相与月面姿态。

当前 V4 版本包含：

- 地面观测者视角下的真实月相、月球高度、方位、距离和视直径；
- 月球天平动、月面位置角、地照、晨昏线、经纬网和月面地标；
- 4K 基础月面与按需加载的 8K / 16K 月面、高程瓦片；
- 下一次月出、下一次月落以及当前月球方向；
- 当地可见月食、月掩亮星与月掩行星预测；
- 简洁、专业两种使用模式，以及中文、英文界面；
- 桌面和手机浏览器交互；
- 浏览器本地生成的完整月面与当前视野 PNG 图片。

项目适合公众科普、月相探索、摄影构图参考和一般观测规划。

## 主要功能

### 真实月面渲染

- 使用 WebGL 实时绘制球面月球，不依赖固定月相序列图；
- 根据太阳、月球和观测者的实时位置生成亮面、暗面与晨昏线；
- 根据观测地点呈现 topocentric（站心）月相与地表视差；
- 呈现地心光学天平动、日周视差造成的姿态变化以及月面位置角；
- 使用月球高程数据参与法线、掠射光阴影和月缘细微起伏计算；
- 支持地照强度、表面特征对比度、地标、经纬网和晨昏线显示；
- 以 4K 月面作为稳定基础图层，并在需要更多细节时按当前视野加载 8K / 16K 色彩与高程瓦片；
- 高清瓦片通过纹理图集按需进入显存，避免一次性解码整张 16K 图片。

### 地点与时间

- 使用浏览器定位获取当前经纬度；
- 直接输入 WGS-84 纬度和经度；
- 使用常用城市快速切换观测地点；
- 通过高德地图选点；中国大陆地图坐标会从 GCJ-02 转换为 WGS-84 后参与天文计算；
- 根据经纬度识别 IANA 时区，并按照所选日期处理夏令时；
- 可关闭自动时区，改用固定 UTC 偏移；
- 支持按 5 分钟、1 小时或 1 天前后调整；
- 支持多档正向时间流速和反向播放。

### 观测信息

专业模式提供以下实时观测量：

- 亮面比例与月相名称；
- 相位角；
- 月球高度与方位；
- 地月距离；
- 经度、纬度天平动；
- 月面位置角。

地图显示观测点指向月球的实时方向，以及当前时刻之后的下一次月出和下一次月落方向。方位角以正北为 `0°`，顺时针增加。

### 月食预测

- 搜索当地未来可见的月食；
- 区分半影月食、月偏食和月全食；
- 显示 P1、U1、U2、MAX、U3、U4、P4 等接触阶段；
- 标记月球在当地地平线以上的可见区间；
- 支持跳转当地最佳时刻、拖动时间轴和播放当地可见过程；
- 提供 Danjon 色阶，以及可选的 HDR 曝光与绿松石带视觉近似。

月食色彩属于受公开科学资料约束的可调视觉近似，不是对某次月食大气颜色的精确预报。

### 月掩星与月掩行星

- 搜索有限内置目标表中的近期月掩亮星事件；
- 搜索当地未来月掩行星事件；
- 显示掩始、最接近和掩终状态及时间轴；
- 标记事件发生时月球是否位于当地地平线以上；
- 支持跳转事件并播放前后过程；
- 导出时保留当前有效的被掩星点或行星视觉。

月掩搜索采用轻量级浏览器端计算与有限目标表，适合交互演示和初步规划，不代替专业星历、IOTA 预报或掩星观测软件。

### 图片导出

- 简洁模式保留“导出完整月面”和“导出当前视野”两个并列入口；
- **导出完整月面**：无论当前是否放大，始终生成固定 `4800 × 4800`、包含完整月球的 PNG；
- **导出当前视野**：按照浏览器中正在观看的缩放、平移和画面比例进行构图，输出图像保持当前视野宽高比，长边为 `4800 px`；即使处于 `1×`，也按当前浏览器视野导出；
- 当前视野涉及暗空区域时，会保留与完整月面风格统一的辉光和星点；
- 图片底部居中标注城市、当地时间、UTC 偏移和经纬度；为降低精确位置暴露，经纬度保留至小数点后两位；
- 专业模式按当前天文状态导出，并保留适用的月食或月掩目标；
- 月球位于当地地平线下时，页面会给出短暂提示，不生成模拟人眼观测效果的图片；
- 生成过程完全在浏览器本地完成，图片不会上传到项目服务器。

## 使用说明

### 简洁模式

1. 打开页面后，应用以当前时间显示默认地点的真实月面。
2. 点击底部城市可快速切换到此刻能够看到月球的其他地点。
3. 点击“更多”可使用当前位置或在地图上选择地点。
4. 桌面端使用滚轮缩放；双击可在默认视图与 `2×` 视图间切换。
5. 手机端在月面区域双指缩放，放大后可单指拖动查看细节。
6. 点击“导出完整月面”生成固定 `4800 × 4800` 的完整月球图片；点击“导出当前视野”保留当前屏幕中的缩放、平移与画面比例。

简洁模式跟随真实时间，并隐藏较复杂的天文参数，适合日常查看和快速分享。

### 专业模式

1. 点击页面右上角“专业”。
2. 在“运行模式”中选择：
   - **真实天文模式**：画面由地点和时间唯一驱动；
   - **自由演示模式**：分别观察天平动、旋转和晨昏线等变量。
3. 在“观测地点”中输入经纬度、使用当前位置、选择常用城市或在地图选点。
4. 在“观测时间”中选择当地民用时间。自动时区开启时，系统按地点对应的 IANA 时区和日期换算 UTC。
5. 使用时间按钮或“推进时间”观察月面随时间连续变化。
6. 查看“观测信息”，或进入“月食预测”“月掩星预报”选择事件。
7. 在“显示与贴图”中调整地照、对比度和辅助标注。
8. 点击“导出”生成当前天文状态对应的图片。

## 精度与适用范围

Astronomy Engine 上游项目将其核心天文位置计算目标描述为与权威模型相比保持约 `±1 arcminute` 的精度，但这不代表本应用的全部输出具有相同误差范围。最终显示还会受到以下因素影响：

- 输入地点、海拔、设备时间的准确性；
- 大气折射近似，特别是月球接近地平线时；
- IANA 时区边界的简化与历史规则；
- 月掩目标坐标、目标数量和浏览器端搜索步长；
- 月面纹理、高程采样、着色和视觉增强处理；
- 浏览器、GPU、屏幕缩放比例与可用显存。

本项目不用于航天器导航、测量定标、安全关键决策或要求专业星历精度的工作。正式观测、科研或工程用途请复核权威星历和原始科学数据。

## 隐私与网络请求

当前版本没有用户账户、项目后端数据库或自建分析服务。天文计算、月面渲染和图片导出主要在浏览器本地完成。

- 页面、Astronomy Engine、时区库、基础月面和瓦片均由本项目的 GitHub Pages 静态提供；
- 使用地图时会连接高德地图服务；
- “我的位置”只会在用户授权后调用浏览器 Geolocation API；定位过程仍受浏览器、操作系统和设备定位服务的隐私策略约束；
- 导出的图片保留在用户设备中，不会上传到项目服务器。

## 本地运行

项目是静态网站，不需要构建步骤。由于高清瓦片、浏览器安全策略和定位能力的限制，建议通过本地 HTTP 服务预览，而不是直接双击 `index.html`。

```bash
git clone https://github.com/moon-observer/moon-viewer.git
cd moon-viewer
python3 -m http.server 8000
```

随后访问：

```text
http://localhost:8000/
```

建议使用较新的 Safari、Chrome、Edge 或 Firefox，并确保浏览器支持 WebGL、Canvas、ES2020 与 WebP。定位功能通常要求 HTTPS 或 `localhost` 安全上下文。

## 技术说明

- 页面采用静态单页结构，主要界面与渲染逻辑集中在 `index.html`；
- WebGL 负责月球表面、受光、地照、地形与月食影锥，Canvas 负责辅助标注；
- 高清色彩和高程资源采用等距圆柱投影分块，通过清单选择分辨率；
- 纹理图集只保存当前视野需要的瓦片，以控制网络、解码与 GPU 内存压力；
- 天文计算、事件搜索和图片合成均在浏览器端执行；
- 仓库可直接由任意静态文件服务器托管。
